# Issue tracker: Linear

Issues and PRDs for this repo live in Linear. Do not use GitHub Issues for repo work. Use the Linear plugin for reading and updating issues.

## Conventions

- Create issues in the `Gravity` team.
- Add new issues to the `Gravity - Harness & Notes` project.
- Apply the `Ready for Agent` Team label to issues that an agent can handle independently without human supervision.
- Apply the `Human` Team label to issues that require human implementation or human-in-the-loop supervision.
- Do not publish planning or implementation work to GitHub Issues for this repo.

## When a skill says "publish to the issue tracker"

Create a Linear issue in the `Gravity` team and add it to the `Gravity - Harness & Notes` project.

## When a skill says "fetch the relevant ticket"

Use the Linear plugin to read the issue and its current labels, state, comments, and project context.

## When a skill needs to update triage or status

Use the Linear plugin to update labels, assignment, state, comments, and project links directly in Linear.
