# Context Map

## Contexts

- [Agent Harness](./CONTEXT.md) - continuity, project attachment, execution, runtime activity, and recovery lifecycle
- [Gravity Notes](./docs/gravity-notes/CONTEXT.md) - note authoring, filesystem-backed organization, canvas editing surface, and AI-proposed changes

## Relationships

- **Agent Harness → Gravity Notes**: The agent operates on **Notes** through the **Scratchpad** when the user delegates writing or organization tasks from a **Thread**. The **Notebook Root** is independent from any **Project Context Attachment**.
